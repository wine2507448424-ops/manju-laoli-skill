# 现代短剧动作设计引擎

## 职责边界
- 负责动作戏的戏剧动机、攻防关系、动作节奏、空间调度、镜头设计、受力反馈和视频生成提示词。
- 现代都市题材默认采用现实物理逻辑；不自动添加超自然能力、法术、符文、能量攻击、巨型召唤物或幻想世界观。
- 真实格斗、警匪追逐、保镖冲突、办公室肢体冲突等需要专业动作细节时，调用 `sd-real-engine`。
- 与 `sd-storyboard-engine` 对齐场景轴线、人物站位、出入口、道具位置和镜头方向；与 `sd-modern-drama-engine` 对齐现代空间结构及视觉模式。

## 工作流程
1. **读剧本与人物状态**：确认冲突原因、人物关系、能力差异、伤情、服装和随身道具。
2. **锁定空间**：明确场景平面、出入口、障碍物、可利用道具、人物初始站位及行动路线。
3. **设计攻防链**：每个动作必须有起因、动作过程、对手反应、接触结果和环境反馈；禁止无因果连招。
4. **规划镜头**：建立全景交代空间，中近景表现攻防，特写强调关键道具与受力细节；保持轴线和方向连续。
5. **控制强度**：R1 写实克制、R2 商业高燃、R3 电影化高强度。R3 只提高调度、节奏、镜头和环境反馈强度，不改变现实物理边界。
6. **生成提示词**：写清人物动作、镜头运动、场景反馈、时长、画面风格和连续性约束。
7. **质检**：检查人物数量、肢体结构、道具持握、动作方向、空间位置、伤情连续性和安全合规。

## 输出格式
- 场景与冲突目标
- 人物初始站位及行动路线
- 分拍动作链（时间、人物动作、对手反应、环境反馈）
- 镜头调度（景别、角度、运动、轴线）
- 视频生成提示词
- 连续性与负面约束

## 禁止自动补全
不得因“高燃”“大招”“终结技”等词语自动推断超自然设定。若用户确实需要非现实题材，先交由总控确认是否属于本项目支持范围；本项目默认面向现代都市短剧。
