# 现代都市场景库

每个场景建立唯一SCN编号，先锁拓扑，再写美术细节。场景卡必须包含：边界形状、入口出口、门窗位置、固定家具、可移动家具、主光方向、人物行动区、摄影机禁入区、环境声源、状态变体。

| 类别 | 场景类型 | 必须锁定的结构要素 |
|---|---|---|
| 企业 | 总裁办公室 | 入口门、办公桌朝向、主位/客位、会客沙发、落地窗、展示柜 |
| 企业 | 会议室/董事会厅 | 长桌轴线、主位、屏幕、入口、每席座次 |
| 企业 | 集团大堂 | 旋转门/闸机、前台、等候区、电梯厅、纵深轴线 |
| 企业 | 地下车库 | 车位编号、车头方向、立柱、坡道、电梯入口 |
| 居住 | 豪宅客厅 | 入户门、楼梯、主沙发、单椅、壁炉/电视墙、落地窗 |
| 居住 | 公寓/卧室 | 房门、床头方向、衣柜、窗户、卫生间入口 |
| 商务 | 高级餐厅/会所 | 入口、主桌、卡座、吧台、服务通道、背景光源 |
| 商务 | 酒店大堂/套房 | 前台/房门、电梯、沙发区、床与窗的相对位置 |
| 医疗 | 病房/急诊走廊 | 病床方向、床头设备、门、护士站、走廊动线 |
| 司法 | 律所/询问室 | 桌椅相对位置、单向观察窗、录音设备、出入口 |
| 城市 | 天台/雨夜街道 | 安全出口、护栏、道路方向、可用遮挡、主光源 |

## 状态变体
同一SCN可登记白天/夜晚、整洁/凌乱、灯开/灯关、门开/门关、雨前/雨后等状态。状态变化必须登记，不得暗中改变空间拓扑。
