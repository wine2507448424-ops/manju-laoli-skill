# 视觉模式圣经

## LIVE_ACTION｜真人写实
- 目标：现代真人短剧的摄影真实感，演员外形、服装、场景陈设跨镜稳定。
- 摄影：明确焦段倾向、景别、机位高度、景深、曝光与运动方式；避免无动机的漂浮镜头。
- 光线：说明主光方向、色温关系、窗外/实景光源和补光逻辑；同场次光向保持连续。
- 表演：以可拍摄的动作、视线、呼吸、微表情和身体重心描述，不用抽象情绪替代表演。
- 材质：皮肤、头发、玻璃、金属、木材、皮革和织物呈现真实反射与纹理。

## 3D_CG｜3D写实动画
- 目标：电影级三维动画写实风，角色与场景资产可复用。
- 渲染：锁定角色比例、材质响应、毛发/布料系统、全局光照和体积效果。
- 摄影：遵守真实镜头逻辑，但可适度强化构图、景深和运动曲线。
- 表演：明确动作弧线、重心变化、停顿和面部控制；避免模型每镜重置姿态。
- 材质：同一资产的粗糙度、金属度、透明度和纹理尺度跨镜一致。

## 共用锁
空间拓扑、门窗方向、家具坐标、人物路径、180°轴线、道具状态和镜头覆盖在两种模式中完全共用。切换视觉模式不允许重排场景。
